# מי המתחזה? 🕵️

משחק "המתחזה" בעברית לכל המשפחה (גילאי 5–12). כל שחקן משחק מהטלפון שלו – צריך לפחות 3 שחקנים.

## איך משחקים
1. נכנסים לאתר בטלפון.
2. שחקן אחד לוחץ **"פתיחת חדר חדש"** – הוא המנהל ומקבל קוד בן 4 ספרות (וגם קוד QR).
3. שאר השחקנים מכניסים את הקוד (או סורקים את ה-QR) ולוחצים **"הצטרפות"**.
4. כולם מקבלים את אותה מילה סודית – חוץ מהמתחזה! כל אחד אומר מילת רמז אחת, ובסוף מצביעים מי המתחזה.

> הטלפון של המנהל מחזיק את המשחק – צריך להשאיר אותו פתוח על הדף.

## העלאה ל-GitHub Pages
1. יוצרים מאגר (repository) חדש ב-GitHub, ציבורי.
2. **Add file → Upload files** – גוררים את `index.html`, `game.js` ו-`README.md` → **Commit changes**.
3. **Settings → Pages** → תחת *Branch* בוחרים `main` ו-`/ (root)` → **Save**.
4. אחרי דקה-שתיים המשחק זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`
