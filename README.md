# מי המתחזה? 🕵️

משחק "המתחזה" בעברית לכל המשפחה (גילאי 5–12). כל שחקן משחק מהטלפון שלו – צריך לפחות 3 שחקנים.

## איך משחקים
1. נכנסים לאתר בטלפון.
2. שחקן אחד לוחץ **"פתיחת חדר חדש"** – הוא המנהל ומקבל קוד בן 4 ספרות (וגם קוד QR).
3. שאר השחקנים מכניסים את הקוד (או סורקים את ה-QR) ולוחצים **"הצטרפות"**.
4. כולם מקבלים את אותה מילה סודית, עם ציור וכפתור השמעה – חוץ מהמתחזה!
5. כל אחד אומר מילת רמז אחת, ובסוף מצביעים מי המתחזה. המתחזה יכול לנסות לנחש את המילה פעם אחת.

## קבצים
| קובץ | תוכן |
|---|---|
| `index.html` | הדף והעיצוב |
| `game.js` | לוגיקת המשחק, החיבור בין הטלפונים והממשק |
| `words.js` | מאגר המילים: 292 מילים ב-10 נושאים, לכל מילה ציור |

כדי להוסיף מילים עורכים את `words.js` – כל מילה היא זוג `['מילה', 'אימוג׳י']`.

## העלאה ל-GitHub Pages
1. יוצרים מאגר (repository) ציבורי ב-GitHub.
2. **Add file ← Upload files** – גוררים את כל הקבצים ← **Commit changes**.
3. **Settings ← Pages** ← Branch: `main`, תיקייה `/ (root)` ← **Save**.
4. אחרי דקה-שתיים המשחק זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`
